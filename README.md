# MarisServerDatapack
# 中文
适用于 Maris 服务器的 Minecraft 数据包。

该数据包具有的功能：
1. 玩家死亡后会掉落玩家头颅。
2. 你可以控制天气，只需输入命令：“/trigger mrs”即可打开控制器。
3. 降低了末影人搬运方块导致服务器卡顿的风险。 末影人将只会运输南瓜和西瓜以及雕刻好的南瓜。
4. 添加了一些合成表。
5. 此数据包是测试版，更多内容正在制作中......
