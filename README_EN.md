# SSL-SeaSoleLandsServer Datapack
# ENGLISH
A Minecraft datapack for SeaSoleLands(SSL) minecraft server.

Features of this data pack:
1. Players will drop their heads after death.
2. You can control the weather, just type the command: "/trigger ssl" to turn on the controller.
3. Reduced the risk of endermen carrying blocks causing server lag. Endermen will only transport pumpkins, watermelons and carved pumpkins.
4. Added some crafting tables.
5. This data pack is a beta version, more content is in the works...
